# T1001 — 計算A+B（新手教程）

## 1. 題目摘要
輸入兩個整數 A、B，輸出 A+B 的結果。

## 2. 核心觀念
- cin：標準輸入
- cout：標準輸出
- int：整數資料型態
- +：加法運算子

## 3. 解題思路
1. 宣告兩個整數 A、B。
2. 使用 cin 讀取 A 和 B。
3. 計算 A+B。
4. 使用 cout 輸出結果。

## 4. 複雜度分析
- Time Complexity: O(1)
- Space Complexity: O(1)

原因：
只進行固定次數的輸入、加法與輸出，
不會隨著輸入數值變大而增加迴圈次數。

## 5. 易錯觀念
- 不要輸出題目沒有要求的文字。
- 注意 int 的整數範圍。
- cin 可以讀取以空白或換行分隔的數字。
