# T1068 — 救援 (Rescue)

## 1. 題目摘要 (Problem Summary)

大本營位於平面座標原點 `(0, 0)`，有 `n` 個需要救援的屋頂。救生船每次從大本營前往一個屋頂，接完該屋頂所有人後，沿原路返回大本營；依序處理全部屋頂。

- 船速：`50` 公尺／分鐘。
- 每人上船花 `1` 分鐘，下船花 `0.5` 分鐘。
- 輸入：整數 `n`，後續 `n` 行各為 `x y r`，表示屋頂座標及人數。
- 輸出：完成全部救援所需的時間（分鐘），**向上取整**。

## 2. 核心觀念 (Key Concepts)

- **Euclidean Distance（歐幾里得距離）**：從原點到 `(x, y)` 的距離為 `sqrt(x*x + y*y)`。
- **Round Trip（往返）**：船每次要回大本營，因此航行距離是單程的兩倍。
- **時間 = 距離 / 速度**：每個屋頂航行時間為 `2 * sqrt(x*x + y*y) / 50`。
- **人員上下船時間**：每人總共 `1 + 0.5 = 1.5` 分鐘，所以 `r` 人要 `1.5 * r` 分鐘。
- **Ceiling（向上取整）**：全部時間加總後才向上取整，不是每趟各自取整。

## 3. 解題思路 (Approach)

1. 初始化總航行距離 `m = 0`、總上船時間 `uptime = 0`、總下船時間 `downtime = 0`。
2. 每讀入一組 `(x, y, r)`，用畢氏定理計算單程距離。
3. 將兩倍單程距離加到 `m`，代表每趟往返。
4. 將 `r` 加到 `uptime`；將 `0.5 * r` 加到 `downtime`。
5. 所有屋頂處理完，計算 `mtime = m / 50`，再把三項時間相加。
6. 對**總時間**向上取整，輸出整數分鐘。

也可以把上述計算合成一個公式：

$$
T = \left\lceil \sum_{i=1}^{n} \left(\frac{2\sqrt{x_i^2+y_i^2}}{50}+1.5r_i\right) \right\rceil
$$

**題目範例**：屋頂 `(30, 40)` 距離原點 `50` 公尺；往返需 `2` 分鐘。`3` 人上下船共需 `4.5` 分鐘，總計 `6.5` 分鐘，因此輸出 `7`。

## 4. 複雜度分析 (Complexity Analysis)

- **Time Complexity：O(n)**。每個屋頂只讀取及計算一次，每次計算為常數時間。
- **Space Complexity：O(1)**。僅使用固定數量變數，不需儲存所有屋頂資料。

## 5. 易錯觀念 (Common Mistakes)

- 忘記**往返**，只算原點到屋頂的單程距離。
- 把每人上下船 `1.5` 分鐘誤當成每個屋頂固定 `1.5` 分鐘。
- 對每一趟各自向上取整；題目要求的是**整體加總後**向上取整。
- 使用 `round()`（四捨五入）或直接轉 `int`（截去小數），而非 `ceil()`（向上取整）。
- 原 AC 程式將屋頂數 `n` 宣告成 `double`；雖然在本題整數輸入下可用，但 `int n` 更符合題意。
- 浮點數可能存在精度問題；`ceil(total)` 較能清楚表達意圖，但極接近整數的計算仍需注意誤差。

## 7. 其他解法 (Alternative Solutions)

除了先加總航行距離、上船時間、下船時間，也可以逐個屋頂直接累加當趟時間。`hypot(x, y)` 等同計算兩座標到原點的直線距離：

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    int n;
    cin >> n;
    double total = 0;
    for (int i = 0; i < n; ++i) {
        double x, y;
        int r;
        cin >> x >> y >> r;
        total += 2.0 * hypot(x, y) / 50.0 + 1.5 * r;
    }
    cout << (int)ceil(total) << '\n';
}
```

此寫法依然是 **O(n)** 時間與 **O(1)** 額外空間。
