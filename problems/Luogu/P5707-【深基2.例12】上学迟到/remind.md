# Luogu P5707 — 【深基2.例12】上學遲到

## 1. 題目摘要 (Problem Summary)

學校規定最晚必須在 **08:00** 抵達。家到學校距離為 `s` 公尺，行走速度為 `v` 公尺／分鐘；途中還要花 **10 分鐘** 做垃圾分類。求在不遲到的前提下，**最晚可以幾點出門**。

- **輸入**：一行兩個正整數 `s v`，分別表示距離與每分鐘的行走速度，且 `1 ≤ s, v ≤ 10^4`。
- **輸出**：24 小時制的 `HH:MM`，小時與分鐘都必須是兩位數，不足補 `0`。
- **特殊條件**：只能在每分鐘的第 0 秒出門，因此行走時間若不是整數分鐘，就必須**向上取整**；出門時間可能落在前一天，但題目保證不需要提前超過一天。

## 2. 核心觀念 (Key Concepts)

- **Ceiling Division（整數除法向上取整）**：`(s + v - 1) / v`，對正整數 `s, v` 等同於 `ceil(s / v)` 的數學結果，但不需要使用浮點數。
- **Time Conversion（時間換算）**：一天 `24 × 60 = 1440` 分鐘；上午 08:00 是當天第 `8 × 60 = 480` 分鐘。
- **Backward Calculation（時間倒推）**：最晚出門時刻 = 08:00 − 垃圾分類 10 分鐘 − 行走時間。
- **Day Rollover（跨日處理）**：結果為負數時，加上 `1440`，換成前一天的 24 小時制時刻。
- **Integer Division / Modulo（整除與取餘數）**：`minute / 60` 得到小時，`minute % 60` 得到分鐘。
- **Formatted Output（格式化輸出）**：`printf("%02d:%02d", h, m)` 會將小時、分鐘以至少兩位數顯示，不足時補 `0`。

## 3. 解題思路 (Approach)

### 先建立公式

08:00 代表 `480` 分鐘；扣除固定的垃圾分類時間後，剩下：

$$480 - 10 = 470$$

走路需要的完整分鐘數為：

$$t = \left\lceil \frac{s}{v} \right\rceil$$

因此最晚出門時刻，以當天 00:00 為起點計算：

$$yyy = 470 - t$$

### 依照原始 AC 程式執行

1. `cin >> s >> v`：讀入路程與速度。
2. `int t=(s+v-1)/v;`：計算必須預留的行走分鐘數。由於 `s`、`v` 都是正整數，整數除法即可完成向上取整。
3. `int yyy = 470-t;`：從 07:50（已扣除垃圾分類 10 分鐘）再倒推走路時間。
4. `if (yyy >= 0)`：當結果仍是當天的分鐘數，直接輸出。
5. `else`：若是負數，代表需要在前一天出門；`yyy = yyy+1440;` 將時間移回有效的 24 小時範圍。題目保證最多跨一天，所以加一次就足夠。
6. `yyy / 60` 與 `yyy % 60`：分別轉成小時、分鐘，再用 `%02d:%02d` 輸出。

### 原始 AC Code（完整保留，未修改）

```cpp
#include <bits/stdc++.h>
using namespace std;

int main()
{
    int s, v;
    cin >> s >> v;
    int t=(s+v-1)/v;
    int yyy = 470-t;

    if (yyy >= 0)
    {
        printf("%02d:%02d", yyy / 60, yyy % 60);
    }
    else
    {   
        yyy = yyy+1440;
        printf("%02d:%02d", yyy / 60, yyy % 60);
    }


}
```

### 手動追蹤：`100 3`

| 步驟 | 計算 | 結果 |
|---|---|---|
| 走路分鐘數 | `(100 + 3 - 1) / 3` | `34` |
| 最晚出門的分鐘數 | `470 - 34` | `436` |
| 是否跨日 | `436 >= 0` | 否 |
| 小時 | `436 / 60` | `7` |
| 分鐘 | `436 % 60` | `16` |
| 最終輸出 | `%02d:%02d` | `07:16` |

**正確性原因**：`t` 是足夠走完路程的最小整數分鐘數；再預留 10 分鐘，從 08:00 倒推恰好得到最晚可出門的整分鐘時刻。任何再晚一分鐘的出發時間都不足以在 08:00 前完成全部行程。

## 4. 複雜度分析 (Complexity Analysis)

- **Time Complexity：O(1)**：只做固定次數的加減乘除、比較與輸出，沒有迴圈。
- **Space Complexity：O(1)**：只使用 `s`、`v`、`t`、`yyy` 四個整數變數，沒有使用陣列或容器。

## 5. 易錯觀念 (Common Mistakes)

- **把 `s / v` 直接當成所需分鐘**：例如 `100 / 3` 使用整數除法只會得到 `33`，但實際需要 `34` 分鐘；若少算一分鐘，就會遲到。
- **向上取整後又額外減一分鐘**：先前嘗試以 `double` 倒推時間，再轉為 `int` 並減少分鐘數，容易出現 Off-by-one Error（差一錯誤）。目前 AC 版先精確算出 `t`，不必再對結果額外減 `1`。
- **混淆 08:00 與 07:50**：`470` 並非 08:00，而是已扣掉垃圾分類 10 分鐘的 `07:50`。若寫成 `480 - t`，就會漏掉固定的 10 分鐘。
- **忘記處理負數分鐘**：例如 `yyy = -1` 代表前一天 `23:59`，不能直接把 `-1` 拿去計算輸出的時、分；原程式先加 `1440` 再輸出。
- **忽略 `yyy == 0`**：`0` 就是 `00:00`，屬於有效時間，所以原程式判斷 `yyy >= 0` 是正確的。
- **忘記補零**：`printf("%d:%d", 7, 6)` 只會輸出 `7:6`，題目要求的是 `07:06`。
- **誤解 C++ 的負數整數除法**：C++ 整數除法朝 `0` 截斷，負數取餘數也不會自動變成 0 到 59；需要先做跨日正規化。

## 7. 其他解法 (Alternative Solutions)

原本的 `if / else` 已經 AC，**不需要更換**。由於兩個分支的 `printf` 完全相同，可以先處理跨日，再統一輸出：

```cpp
int t = (s + v - 1) / v;
int yyy = 470 - t;
if (yyy < 0)
    yyy += 1440;
printf("%02d:%02d", yyy / 60, yyy % 60);
```

也可以用取模正規化處理跨越多天的情況：

```cpp
int yyy = 470 - (s + v - 1) / v;
yyy = (yyy % 1440 + 1440) % 1440;
printf("%02d:%02d", yyy / 60, yyy % 60);
```

第二種寫法在 `yyy` 是負數時也能得到 `0` 到 `1439` 的結果；但本題保證不需提前超過一天，因此原 AC 版加一次 `1440` 就足夠。以上都是補充寫法，**不取代原始 AC Code**，時間及額外空間複雜度同為 O(1)。
