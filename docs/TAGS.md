# 標籤（Tags）命名規範

**題目資料夾按平台分類；Tags 則提供跨平台的演算法檢索。**

建議每題選 2–4 個最具代表性的標籤。使用相同拼字與大小寫，避免 `DP`、`Dynamic Programming` 被視為不同分類。

| 領域 | 推薦標籤 |
|---|---|
| 基礎 | `Array`, `String`, `Math`, `Simulation`, `Implementation` |
| 資料結構 | `Hash Map`, `Set`, `Stack`, `Queue`, `Heap`, `Deque` |
| 搜尋/排序 | `Sorting`, `Binary Search`, `Two Pointers`, `Sliding Window`, `Prefix Sum` |
| 動態規劃 | `DP`, `Knapsack`, `LIS`, `Digit DP`, `Bitmask DP` |
| 貪心 | `Greedy`, `Intervals` |
| 圖論 | `Graph`, `BFS`, `DFS`, `Shortest Path`, `Topological Sort`, `Union Find`, `MST` |
| 樹 | `Tree`, `Binary Tree`, `Segment Tree`, `Fenwick Tree`, `LCA` |
| 數學/字串 | `Number Theory`, `Combinatorics`, `Geometry`, `KMP`, `Trie` |
| 其他 | `Backtracking`, `Bitmask`, `Recursion`, `Divide and Conquer` |

- `Hash Map` 與 `Map` 選一個：建議用 `Hash Map` 指稱散列表。
- `Two Pointers` 與 `Sliding Window` 可以同時使用，但只在解法真的同時涉及兩者時。
- 題目難度填 `difficulty`，**不要**再當 Tags，否則分類會混雜。
- 平台名填 `platform`，**不要**當 Tags，避免雙重分類。
